# KidCare — หน้าแรกแบบแดชบอร์ด (Design Spec)

วันที่: 2026-09-30 · ต่อยอดจาก `2026-09-30-kidcare-phase1-design.md` (Phase 1 core ที่ deploy แล้ว)

## 1. เป้าหมาย

หน้าแรก (`/`) เปลี่ยนจาก "รายการนัด + การ์ดลูก" เป็นแดชบอร์ดภาพรวมของลูกทุกคน แล้วแตะการ์ดลูกเพื่อเข้าหน้ารายละเอียด (`/children/:id`) เหมือนเดิม ใช้เฉพาะข้อมูลที่มีใน Phase 1 (วัคซีน นัดหมาย การแพ้) — กราฟการเติบโต/การป่วยรอเฟส 2–3

## 2. โครงหน้า (บนลงล่าง)

1. **Stat tiles 4 ช่อง** (grid 2×2 บนมือถือ)
   - เลยกำหนด: จำนวนเข็มที่ `!given && dueDate < today` ของลูกทุกคน (ตัวเลขสีแดง + ไอคอน)
   - นัดถัดไป: รายการที่ใกล้ที่สุดที่ `date >= today` (เข็มหรือนัดหมอ) → "วันนี้" / "พรุ่งนี้" / "อีก N วัน" + บรรทัดเล็ก `วัน/เดือน · ชื่อเล่น · เรื่อง`; ไม่มี → "—"
   - ฉีดครบตามวัย: `given / (given + overdue)` ของเข็มที่ถึงกำหนดแล้วหรือฉีดแล้ว (นับเฉพาะเข็มที่ `given` หรือ `dueDate <= today`) → เปอร์เซ็นต์ปัดเต็ม; ไม่มีเข็มที่ถึงกำหนด → "—"
   - นัด 30 วันข้างหน้า: จำนวนรายการ (เข็มค้าง + นัดหมอที่ยังไม่ไป) ที่ `today <= date <= today+30`
2. **การ์ดลูก** (1 ใบ/คน เรียงตามวันเกิด แตะทั้งใบ → `/children/:id`)
   - ชื่อเล่น (หรือชื่อ), อายุ, ป้ายแพ้ (แดง "แพ้ N" / เทา "ไม่มีประวัติแพ้")
   - แถบความคืบหน้าวัคซีน (ทุก series ของเด็กคนนั้น): 3 ช่วง ฉีดแล้ว (เขียว) / เลยกำหนด (แดง + ลายเส้นทแยง) / ยังไม่ถึงวัย-ยังไม่นัด (เทา) กว้างตามจำนวน มีช่องว่าง 2px ระหว่างช่วง ปลายมน 4px + ข้อความตัวเลขใต้แถบทั้ง 3 ค่า (สีไม่ใช่ตัวสื่อความหมายเดียว)
   - "ถัดไป: {วัคซีน} เข็ม {n} · {วันที่}" (เข็มค้างที่ dueDate ใกล้สุด ≥ วันนี้ ถ้าไม่มีแต่มีเข็มเลยกำหนด → "มีเข็มเลยกำหนด N เข็ม")
3. **กราฟแท่งนัด 12 เดือนข้างหน้า** — แกน x = เดือน (เดือนนี้ + 11 เดือน, ชื่อเดือนไทยย่อ), แท่งซ้อนตามลูก (สีต่อเด็กคงที่ตามลำดับวันเกิด: คนที่ 1 `#3987e5`, คนที่ 2 `#d95926`), นับเข็มค้างที่มี dueDate + นัดหมอที่ยังไม่ไป ในเดือนนั้น (ไม่รวมที่เลยกำหนด); legend อยู่เหนือกราฟ (≥2 series); แกน y จำนวนเต็ม; hover/แตะแท่ง → tooltip "ต.ค. 2569 · ต้นกล้า 1 · วินเทจ 2"; ไม่มีข้อมูลเลย → ข้อความ "ไม่มีนัดใน 12 เดือนข้างหน้า"
4. **ไทม์ไลน์วัคซีนตามอายุ** — 1 แถว/ลูก, แกน x = อายุ 0 → max(60 เดือน, อายุเข็มสุดท้าย, อายุวันนี้) ขีดทุก 12 เดือน ("แรกเกิด", "1 ปี", …); จุด 1 จุด/เข็ม วางที่อายุ ณ `givenDate` (ถ้าฉีดแล้วและรู้วัน) หรือ `dueDate`; รูปร่างตามสถานะ: ฉีดแล้ว = วงกลมทึบเขียว, เลยกำหนด = สี่เหลี่ยมข้าวหลามตัดแดง, ยังไม่ถึง = วงกลมกลวงเทา; เข็มที่ฉีดแล้วแต่ไม่รู้วัน / ไม่มี dueDate → ไม่วาด (นับรวมในแถบของการ์ดอยู่แล้ว); เส้นแนวตั้ง "วันนี้" ต่อแถว; legend รูปร่าง+ข้อความ; hover/แตะจุด → tooltip "{วัคซีน} เข็ม {n} · {วันที่} · {สถานะ}"
5. **นัดที่รออยู่ 5 รายการแรก** (ใช้ `UpcomingList` เดิม: เลยกำหนดก่อน แล้วใกล้ถึง) + ปุ่ม "ดูทั้งหมด (N)" → หน้าใหม่ `/appointments` ที่แสดง `UpcomingList` เต็ม + ปุ่ม "นัดหมอ"

สถานะโหลด: ขณะข้อมูลลูก/เข็ม/นัดยังโหลด แสดง "กำลังโหลด…" แทนทั้งแดชบอร์ด (ห้ามแสดง 0 หรือ "ไม่มีนัด" ก่อนข้อมูลมา) · ไม่มีลูก → หน้าว่างเดิม "เพิ่มลูก"

## 3. ข้อมูล

- ต้องใช้ **เข็มทั้งหมด** (รวมที่ฉีดแล้ว) ของลูกทุกคน: เปลี่ยน hook `usePendingDoses` เป็น `useFamilyDoses(fid, childIds)` คืน `{ data, error, loading }` (query ทั้ง collection ต่อเด็ก ไม่มี where) — Home คำนวณเข็มค้างจากข้อมูลนี้เอง (`usePendingDoses` มีผู้ใช้แค่ Home จึงแทนที่ได้)
- ตรรกะทั้งหมดเป็นฟังก์ชัน pure ใน `src/domain/dashboard.ts` พร้อม unit test

## 4. กราฟ

- วาดด้วย SVG ใน React เอง (ไม่เพิ่ม library — bundle 907 kB อยู่แล้ว)
- สี: สีลูก (categorical) ผ่าน validator บน surface `#161a22` แล้ว (ΔE CVD 26.8); สีสถานะ good `#0ca30c` / critical `#d03b3b` / neutral `#6b7280` แยกแยะด้วยสีอย่างเดียวไม่ได้สำหรับตาบอดสีแดง-เขียว → **ต้องมีรูปร่าง/ลาย/ข้อความประกอบเสมอ** (ตามข้อ 2.2, 2.4)
- ข้อความ/ตัวเลขใช้สี text ของธีม ไม่ใช้สี series; เส้น grid/แกนจาง
- ทุกกราฟมี `role="img"` + `aria-label` สรุป และตาราง `sr-only` แสดงข้อมูลเดียวกัน
- tooltip: hover บนเดสก์ท็อป และแตะบนมือถือ (แตะที่อื่นเพื่อปิด), hit target ≥ 24px

## 5. การทดสอบ

- Vitest สำหรับ `src/domain/dashboard.ts` (ทุกฟังก์ชัน รวมขอบ: ไม่มีข้อมูล, วันนี้พอดี, ข้ามปี, เข็มไม่รู้วัน, ลูกไม่มีเข็ม)
- ตรวจใน browser กับข้อมูลจริง (วินเทจ) และหน้าจอขนาดมือถือ 375px
