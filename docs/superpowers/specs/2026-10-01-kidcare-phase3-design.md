# KidCare — เฟส 3 Design Spec

วันที่: 2026-10-01  
ขอบเขต: การเจริญเติบโต (Growth Tracking) + เกณฑ์มาตรฐานเด็กไทย (กรมอนามัย) + รายงานสรุปสุขภาพให้แพทย์ (Health Summary & Print/PDF)

---

## 1. เป้าหมายของเฟส 3

1. **ติดตามการเจริญเติบโต:** บันทึกน้ำหนัก ส่วนสูง และเส้นรอบศีรษะ พร้อมเปรียบเทียบกับเกณฑ์มาตรฐานการเจริญเติบโตของเด็กไทย (กรมอนามัย กระทรวงสาธารณสุข) แยกตามเพศ (ชาย/หญิง)
2. **เห็นแนวโน้มการเติบโตผ่านกราฟ:** กราฟน้ำหนักตามเกณฑ์อายุ และส่วนสูงตามเกณฑ์อายุ พร้อมแถบเกณฑ์ปกติ เพื่อประเมินว่าลูกมีพัฒนาการสมวัยหรือไม่
3. **ส่งออกรายงานสรุปให้หมอ (Medical Summary):** เมื่อต้องพาลูกไปหาหมอที่ รพ. ใหม่ หรือตรวจสุขภาพประจำปี สามารถเปิดหน้าสรุปสุขภาพหรือกด **"พิมพ์ / บันทึก PDF"** ซึ่งรวบรวม:
   - ข้อมูลเด็ก + ประวัติการแพ้ยา/อาหาร (เด่นชัด) + HN ทุก รพ.
   - ประวัติวัคซีนครบถ้วน (ฉีดเมื่อไร เข็มอะไร)
   - ประวัติการเจ็บป่วยและยาที่กำลังรับประทาน
   - การเจริญเติบโตล่าสุด (น้ำหนัก ส่วนสูง)

## 2. โครงข้อมูล Firestore (เฟส 3)

เพิ่ม subcollection `growth` ใต้ `families/{familyId}/children/{childId}`:

```
families/{familyId}
  children/{childId}
    ...
    growth/{growthId}
      id: string
      childId: string
      date: ISODate                  # วันที่วัด เช่น "2026-10-01"
      ageMonths: number              # อายุ ณ วันที่วัด (คำนวณจากวันเกิด)
      weightKg?: number              # น้ำหนัก (กก.) เช่น 12.5
      heightCm?: number              # ส่วนสูง (ซม.) เช่น 88.0
      headCircumferenceCm?: number   # เส้นรอบศีรษะ (ซม.) เช่น 47.0
      notes?: string                 # เช่น "ชั่งตอนฉีดวัคซีน 1 ขวบ"
      createdAt: Timestamp
```

## 3. เกณฑ์มาตรฐานการเจริญเติบโต (Domain Logic)

ใช้เกณฑ์อ้างอิงการเจริญเติบโตของเด็กแรกเกิด - 5 ปี ของ **สำนักโภชนาการ กรมอนามัย กระทรวงสาธารณสุข**:
- แยกเกณฑ์ตามเพศ (`boy` / `girl`) และอายุเป็นเดือน (`0 - 60 เดือน`)
- เกณฑ์น้ำหนักตามเกณฑ์อายุ:
  - น้ำหนักน้อยกว่าเกณฑ์ (< -2 SD)
  - ค่อนข้างน้อย (-2 ถึง -1.5 SD)
  - ตามเกณฑ์ปกติ (-1.5 ถึง +1.5 SD)
  - ค่อนข้างมาก (+1.5 ถึง +2 SD)
  - น้ำหนักเกินเกณฑ์ (> +2 SD)
- เกณฑ์ส่วนสูงตามเกณฑ์อายุ:
  - เตี้ย (< -2 SD)
  - ค่อนข้างเตี้ย (-2 ถึง -1.5 SD)
  - สูงตามเกณฑ์ (-1.5 ถึง +1.5 SD)
  - ค่อนข้างสูง (+1.5 ถึง +2 SD)
  - สูงกว่าเกณฑ์ (> +2 SD)

## 4. หน้าจอและ UI ที่จะเพิ่มในเฟส 3

1. **หน้าการเจริญเติบโต (`/children/:id/growth`)**:
   - แสดงค่าน้ำหนัก ส่วนสูง ล่าสุด พร้อมแถบประเมินผล ("สมส่วน ตามเกณฑ์")
   - กราฟเส้นการเจริญเติบโต (SVG) ซ้อนบนแถบเกณฑ์ปกติของกรมอนามัย
   - ตารางประวัติการวัดย้อนหลัง
   - ปุ่ม "+ บันทึกการเจริญเติบโต"
2. **ฟอร์มบันทึกการเติบโต (`/children/:id/growth/new`)**:
   - วันที่วัด (default วันนี้), น้ำหนัก, ส่วนสูง, เส้นรอบศีรษะ, บันทึก
3. **หน้ารายงานสรุปสุขภาพให้หมอ (`/children/:id/report`)**:
   - จัดเลย์เอาต์สไตล์เวชระเบียนทางการแพทย์ (Medical Summary Sheet)
   - มีปุ่ม **"พิมพ์ / บันทึก PDF"** (Trigger `window.print()` พร้อม Print CSS หน้าเดียว/สองหน้าสะอาดตา)
   - รวมประวัติสำคัญ: แพ้ยา, วัคซีน, โรคประจำตัว/การป่วยล่าสุด, ข้อมูลติดต่อพ่อแม่

## 5. แผนการดำเนินงาน

1. **Step 1:** Types & Security Rules สำหรับ `growth`
2. **Step 2:** ตารางข้อมูลมาตรฐานกรมอนามัย (`src/data/growthStandards.ts`) & Domain Logic (`src/domain/growth.ts` + unit tests)
3. **Step 3:** Repository (`src/lib/repo/growth.ts`) & Hook (`useGrowth`)
4. **Step 4:** หน้ารายการ & กราฟการเติบโต (`Growth.tsx`, `GrowthChart.tsx`, `GrowthForm.tsx`)
5. **Step 5:** หน้ารายงานสรุปสุขภาพเพื่อพิมพ์/PDF (`MedicalReport.tsx` + Print CSS)
6. **Step 6:** เชื่อมต่อลิงก์ในหน้าเด็ก (`ChildDetail.tsx`)
7. **Step 7:** ทดสอบ Unit Tests, Build และ Deploy
